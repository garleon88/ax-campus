기업이 원하는 인재

AI 모델 자체가 아니라, 현장 데이터를 읽고 산업 문제와 연결할 수 있는 융합 인재 수요가 급증하고 있습니다.

핵심 역량

📈

나만의 포지션

AI를 배웠다면 이제 제조업이라는 적용 분야를 가져갈 차례입니다. 전공을 버리는 게 아니라 확장하는 과정입니다.

Curriculum

12주 동안 무엇을 배우나요?

공정 이해부터 하드웨어 제어, 제조 AI 모델링, 대시보드, 최종 프로젝트까지 한 흐름으로 경험합니다.

PHASE 1 1주차
제조 현장과 피지컬 AI 이해
반도체 공정이차전지 공정자동차 공정 디스플레이 공정피지컬 AI 개념센서·설비 데이터 흐름
PHASE 2 2~3주차
하드웨어 제어를 위한 C언어
변수·조건문·반복문포인터·구조체 파일 입출력비트 연산
PHASE 3 4~6주차
임베디드 시스템 실습 (하드웨어 제어)
STM Cortex-M4 보드센서 제어 UART / I2C / SPI / CAN 통신BLE·이더넷 메모리 제어Bootloader
PHASE 4 7~11주차
Python으로 제조 AI 실무 구현
Python 기초Pandas 데이터 전처리 Streamlit 대시보드실시간 데이터 시각화 머신러닝 모델링불량 판정 분류 품질 예측 회귀이상 탐지 예지보전ChatGPT 활용
PHASE 5 12주차
도메인 융합 파이널 프로젝트 🏆
주제 선정·요구사항 정의센서 데이터 수집·저장 AI 모델 적용·검증대시보드 완성 발표 및 시연
